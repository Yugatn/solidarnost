# Солидарность / Solidarnost

Концепция механизма распределения средств между участниками проекта, связанная с социальной архитектурой и принципами взаимного развития.

**Статус:** начальная страница проекта. До появления исходного кода, правил фонда, критериев участия и финансовых процедур репозиторий **не следует считать работающей платёжной системой или действующим фондом**.

Текущие концептуальные источники и авторский канон находятся в [«Амбивалентном Солипсизме»](https://github.com/Yugatn/ambivalent-solipsism). Практические правила, юридический статус, финансовая отчётность и лицензирование будут определены отдельно.
