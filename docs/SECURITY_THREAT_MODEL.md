# Безопасность «Солидарности» — модель угроз v0.1

**Абсолютную неуязвимость гарантировать нельзя.** Цель: не доверять одному каналу, предотвращать кражу денег и приватных данных, делать изменения обнаружимыми и обратимыми.

| Угроза | Защита |
|---|---|
| Кража бот-токена | Secrets manager, ротация, ограниченные права; у бота нет банковских ключей |
| Подделка Telegram webhook | HTTPS, `X-Telegram-Bot-Api-Secret-Token`, ограничения запросов, дедупликация `update_id` |
| Подмена Telegram Mini App login | Проверка `initData` на сервере по правилам Telegram; срок годности; нет доверия клиенту |
| Утечка данных детей и получателей | Минимизация, отдельное шифрованное хранилище, RBAC, журнал доступа, юридическое основание |
| Фальшивые оплаты | Подписанные события провайдера + сверка банка; не доверять скриншотам и чату |
| Повтор платежа | Уникальные ID и идемпотентность, транзакционное резервирование суммы |
| Смена реквизитов мошенником | Повторная аутентификация, период охлаждения, независимая проверка |
| Самоплатёж администратора | Два независимых подписанта, конфликт интересов, банковские лимиты и уведомления |
| Манипуляция жеребьёвкой | Seed commitment до закрытия списка, snapshot, reveal, воспроизведение |
| Взлом приложения / зависимостей | Версионирование, подпись релизов, CI, анализ зависимостей, OWASP ASVS 5 |
| DDoS / шантаж | Rate limits, WAF, резервные копии, план восстановления, emergency stop |

Административные роли: аппаратные passkeys/FIDO2 и дополнительное подтверждение переводов; разведение полномочий при проверке, утверждении и платеже; ревизор может проверить, но не перевести. В Telegram-боте нет функции отправки денег. Токены никогда не помещаются в репозиторий.

Обязательные перед запуском: аудит OWASP ASVS 5 уровня L2 (для переводов усилить), независимый pentest, защита webhook от replay, резервное восстановление, расследование инцидентов, отчёт о конфиденциальности и законности обработки данных.

Источники: [Telegram Bot API](https://core.telegram.org/bots/api), [Telegram Bot Terms](https://telegram.org/tos/bot-developers), [OWASP ASVS 5](https://asvs.owasp.org/).
